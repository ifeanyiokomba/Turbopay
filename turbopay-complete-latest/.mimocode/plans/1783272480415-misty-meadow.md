# Dark Theme Default

## Change
In `src/app/layout.tsx` line 73, change `defaultTheme="light"` to `defaultTheme="dark"`.

## Why
User wants dark mode as the default experience. Users who prefer light can toggle via the existing theme switch in the app shell and settings.

## File
- `src/app/layout.tsx` — one line change

## Verification
1. `npx next dev` — dev server starts
2. Open browser — app loads in dark mode by default
3. Toggle to light in settings — persists across refresh
