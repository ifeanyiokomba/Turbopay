# Make Email Optional on Signup

## Current State
- **Backend:** Both `email` and `phone` are required in the Zod schema (`register/route.ts:16-18`)
- **Prisma:** `email` is `String @unique` (required), `phone` is `String? @unique` (nullable)
- **Frontend:** Both email and phone inputs have `required` attribute (`auth-screen.tsx:301,308`)
- **Login:** Already supports email OR phone OR username lookup (`login/route.ts:53`)

## What Changes
Make both `email` and `phone` optional — at least one must be provided.

## Files to Modify

### 1. Prisma Schema (`prisma/schema.prisma:33`)
- Change `email String @unique` → `email String? @unique`
- This requires a migration: `npx prisma migrate dev --name make-email-optional`

### 2. Register Route (`src/app/api/auth/register/route.ts:13-26`)
- Make `email` optional: `z.string().email().optional()`
- Make `phone` optional: `z.string().regex().optional()`
- Add refinement: `.refine((data) => data.email || data.phone, "Provide at least email or phone")`
- Update `verifyChannel` default: if only phone provided, default to `"SMS"`; if only email, default to `"EMAIL"`
- Update the registration logic to handle missing email (skip email verification, auto-verify phone if provided)

### 3. Auth Screen (`src/components/turbopay/auth-screen.tsx:297-310`)
- Remove `required` from email input (line 301)
- Remove `required` from phone input (line 308)
- Add "(optional)" label to both fields
- Add helper text: "At least one is required for account recovery"
- Add client-side validation: show error if both are empty on submit

### 4. Auth Screen Comment (line 340-342)
- Update comment: "Email and phone are both optional — at least one required"
